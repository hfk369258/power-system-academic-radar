**覆盖评估**：英文刊是**独立投稿的英文期刊，不是中文论文翻译版**（各刊独立编委/审稿）。中文母刊年发 2000+ 篇，英文姊妹刊仅 100~200 篇/年，约覆盖中文刊 5~10% 的精华子集。
- 追"国际前沿" → 英文刊足够（IEEE + Springer 链路覆盖 6/7 本）
- 追"中文全部论文" → 必须靠 NAPSTIC 中文源
- IEEE API 可拿 CSEE JPES / PCMP / IEEE OJPE；Springer API 可拿 MPCE/JEET/JPE；Elsevier API 对本领域无用（均非 Elsevier 旗下）

## 四、Crossref 排除结论
中国电力期刊的 DOI 前缀 10.13334（电机工程学报）、10.13335（电网技术）、10.13336（高电压技术）、10.16081（电力自动化设备等）**都注册在 ISTIC 中国DOI系统，不在 Crossref**。实测 Crossref API 按前缀/ISSN/DOI 查询全部 0 条记录。
→ **Crossref 不可作为中文期刊数据源**；NAPSTIC 详情页是唯一能拿到这些 DOI 的自动化途径。
