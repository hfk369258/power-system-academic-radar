# 万方数据 — 补充源调研结果（2026-07-31 实测）

> 状态：**已探明可用，但尚未做成脚本**（接口未公开、有改版风险）。先记录在这里，需要时再实现。

## 结论

万方可作为「网络首发」新鲜度的补充源。常规页面（d.wanfangdata.com.cn）是 Vue SPA，静态 HTML 无内容，**不能直接 curl**；但存在**免登录、免验证码**的 gRPC-web protobuf 接口，可脚本化抓取：

| 接口 | 方法 | 说明 |
|---|---|---|
| `https://d.wanfangdata.com.cn/Detail.DetailService/getDetailInFormation` | POST | 请求字段 1=`resourcetype`('Periodical')、2=文章ID；返回标题/作者/中英文摘要/DOI/ISSN/**网络首发日期(1.103.86)**/出版状态 |
| `https://d.wanfangdata.com.cn/WwwService.PersonIndexService/searchPeriodicalByIssue` | POST | 请求字段 1=期刊码；可枚举该刊文章 ID（实测含最新 2026 期） |

## 实现要点

- 约 50 行代码实现 gRPC-web 帧编码：`1字节帧标志(0x00/0x80) + 4字节大端长度 + protobuf body`
- 需用 protobuf 解码响应（可用 `google.protobuf` 或手写解析；字段号见上表）
- 推荐流程：每周用 `searchPeriodicalByIssue` 发现新文章 ID → 用 `getDetailInFormation` 取摘要 → 按 DOI 与 NAPSTIC 去重
- 对目标期刊做低频巡检即可覆盖网络首发内容

## 风险与限制

- 接口**未公开、无承诺**：可能改版、加反爬，需监控失败率并备好降级方案
- 更鲁棒但更慢的备选：Playwright 无头浏览器渲染期刊/文章页
- ❌ 维普 qikan.cqvip.com：已被 412 + JS 反爬挑战封死，纯 curl 不可用
- ❌ wf.pub 开放平台：仅收费的「万方选题」API（按次 1-4 点，需 AppKey 签名），无通用题录 API

## 结论

**主路径仍是 NAPSTIC**（稳定、合规、已做成工具）；万方 gRPC 作为「追网络首发最新内容」的进阶补充，实现成本约半天，需要时再接入。
